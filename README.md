# Preparación convocatoria PCA/02/2026

Página de estudio para las pruebas de habilitación como personal de control de acceso (Generalitat de Catalunya).

**Abrir la página:** https://aaron-vg.github.io/Preparacion-Convocatoria-PCA/

Incluye:

- Calculadora de requisitos según el aforo
- Teoría por temas, con referencias a la normativa
- Tests por temas con explicación y artículo
- Simulacro con el formato del examen (20 + 10 + 10 preguntas, 1 h 15 min)
- Fichas de repaso

Todo está en un único archivo, `index.html`. Material de estudio no oficial: ante cualquier duda manda el texto publicado en el DOGC.
